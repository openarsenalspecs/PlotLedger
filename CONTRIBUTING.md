# Contributing to PlotLedger

**PlotLedger** — *The Future of Parcel Intelligence*  
Created by **Roxanne Ardary** | [roxanneardary.com](https://www.roxanneardary.com/)

Thank you for your interest in contributing to PlotLedger! This guide outlines how to properly contribute to the repository, submit improvements, and ensure compliance with licensing and attribution requirements.

---

## How to Contribute

1. **Fork the repository**  
   Create a personal fork of PlotLedger to make changes without affecting the main repository.

2. **Create a feature branch**  
   Use descriptive names such as `feature/add-state-data` or `fix/ai-analysis-bug`.

3. **Make your changes**  
   - Add new features, improve AI analysis scripts, enhance visualization, or update datasets.  
   - Ensure that any new files include appropriate attribution headers referencing **Roxanne Ardary** and [roxanneardary.com](https://www.roxanneardary.com/).

4. **Test your changes**  
   Validate scripts, dataset ingestion, and frontend visualization before submitting.

5. **Submit a pull request**  
   Clearly describe your changes, reference issues if applicable, and confirm that all new files maintain proper attribution.

## Code Style and Best Practices

- Follow consistent Python formatting (PEP8) and JavaScript/React conventions.  
- Document new scripts or components clearly with purpose, inputs, and outputs.  
- Include tests for all major new functionality.  
- Use descriptive commit messages.

---

## Reporting Issues

If you find a bug, data inconsistency, or have a feature request:

1. Check if the issue already exists.  
2. Open a new issue with a descriptive title and detailed explanation.  
3. Include screenshots, data samples, or steps to reproduce where applicable.
